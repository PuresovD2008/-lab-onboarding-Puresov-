# Анализ ассемблерного кода (Дизассемблирование)

## 1. Логика работы инструкций x86-64 (AT&T)

* `movl $0, -4(%rbp)` — инициализация переменной-аккумулятора (`total = 0`) в стеке.
* `movl $1, -8(%rbp)` — инициализация счетчика цикла (`i = 1`) в стеке.
* `jmp .L2` — безусловный переход к проверке условия цикла (цикл с предусловием `while`).
* `.L3:` — тело цикла:
  * `movl -8(%rbp), %eax` и `addl %eax, -4(%rbp)` — прибавление текущего счетчика `i` к аккумулятору `total` (`total += i`).
  * `addl $1, -8(%rbp)` — инкремент счетчика на 1 (`i += 1`).
* `.L2:` — проверка условия:
  * `cmpl $10, -8(%rbp)` и `jle .L3` — сравнение `i` с числом `10`; если `i <= 10`, выполняется переход обратно в тело цикла `.L3`.
* `movl -4(%rbp), %eax` — запись итогового результата (`55`) в регистр возврата `%eax`.

Функция вычисляет **сумму целых чисел от 1 до 10 включительно** (результат равен `55`).

## 2. Эквивалентный код на Python

```python
def calculate_sum():
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total
```
